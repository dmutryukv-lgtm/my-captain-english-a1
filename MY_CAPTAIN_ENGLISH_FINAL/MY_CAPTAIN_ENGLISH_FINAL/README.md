## Встановлення на Windows

1. Скопіювати всі файли в:
`D:\MY_CAPTAIN\`

2. Покласти Excel сюди:
`D:\MY_CAPTAIN\My_Captain_English_A1.xlsx`

3. Встановити залежність:
`pip install openpyxl==3.1.5`

4. Перевірити Excel:
`python check_excel.py`

5. Запустити:
`python my_captain.py`

6. Відкрити:
`http://127.0.0.1:10000`

## Важливо

Не зберігати Telegram token у коді або GitHub.
Excel є джерелом навчального контенту.
HTML не містить копії всієї бази — він отримує дані через Python API.
